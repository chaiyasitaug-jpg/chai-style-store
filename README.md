# CHAI STYLE — Online Clothing Store

เว็บไซต์ร้านเสื้อผ้าเดโมตามโจทย์: อย่างน้อย 2 SKU, ตะกร้าสินค้า, รายการแพ็กสินค้า และใบปะหน้าพัสดุสำหรับพิมพ์

## ไฟล์
- `index.html` เว็บไซต์หลัก
- `config.js` จุดตั้งค่าลิงก์ CSV จาก Google Sheets
- `products.csv` ข้อมูลตั้งต้น 2 SKU สำหรับนำเข้า Google Sheets

## ตั้งค่า Google Sheets
1. สร้าง Google Sheet ใหม่ชื่อ `CHAI STYLE - Product Catalog`
2. Import ไฟล์ `products.csv` เป็นชีตแรก โดยใช้แถวแรกเป็นหัวตาราง
3. กด Share > General access > Anyone with the link > Viewer (ตามที่โจทย์กำหนด)
4. ไปที่ File > Share > Publish to web เลือกชีตสินค้า และเลือก CSV แล้ว Publish
5. คัดลอก URL ที่ได้ ไปใส่ใน `config.js` ตรง `SHEET_CSV_URL`
6. อัปโหลดไฟล์ทั้งโฟลเดอร์นี้ขึ้น GitHub แล้ว Deploy โปรเจกต์บน Vercel

## ฟังก์ชัน
- ดึงรายการสินค้าและสต็อกจาก Google Sheets CSV เมื่อกำหนด URL
- มีข้อมูลสำรอง 2 SKU หากยังไม่ได้ตั้งค่า CSV
- เพิ่ม/ลดจำนวนสินค้าในตะกร้าและคำนวณยอดรวม
- กรอกชื่อ เบอร์โทร ที่อยู่ เพื่อสร้างรายการแพ็กและใบปะหน้าพัสดุ
- ปุ่มพิมพ์ใช้หน้าต่างพิมพ์ของเบราว์เซอร์

หมายเหตุ: ใบปะหน้าเป็นเอกสารตัวอย่างของร้าน ไม่ใช่เลขพัสดุจากบริษัทขนส่งจริง และคำสั่งซื้อยังไม่ได้บันทึกลงฐานข้อมูล/Google Sheets อัตโนมัติ
